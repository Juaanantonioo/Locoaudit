=============================================
ESTADO ACTUAL DEL PROYECTO — LoCoAudit
=============================================
---------------------------------------------
NODO 1 — audit-host
---------------------------------------------

Qué hace: audita el propio equipo donde corre Node-RED.

Herramientas:

  - Módulos nativos de Node.js → obtiene CPU, RAM, disco y datos del SO
    sin necesidad de instalar nada adicional.

  - Lynis: checkbox (opcional) → herramienta de hardening que comprueba más de 300
    aspectos de configuración del sistema (SSH, firewall, actualizaciones...).
    Si no está instalada, el nodo sigue funcionando sin ella.

  - Trivy: checkbox (opcional) → escáner de vulnerabilidades que detecta CVEs en los
    paquetes instalados en el SO comparando contra la base de datos NVD.
    Si no está instalado, el nodo sigue funcionando sin él.

Resultado: dashboard con uso de CPU/RAM/disco, lista de vulnerabilidades
del sistema operativo con su severidad (crítica, alta, media, baja)
y recomendaciones de hardening con el comando concreto para solucionarlo.

---------------------------------------------
NODO 2 — audit-network
---------------------------------------------

Qué hace: audita la exposición de red del equipo.

Herramientas:

  - Escáner TCP nativo → intenta abrir una conexión a cada puerto del equipo;
    si responde, el puerto está abierto. No necesita instalar nada extra.

  - Nmap: checkbox (opcional) → si está instalado, añade detección de versiones de
    servicios, sistema operativo y análisis más profundo de los puertos.

Resultado: dashboard con todos los puertos abiertos del equipo, el servicio
que corre en cada uno, y un aviso cuando algún servicio está en una versión
conocida como insegura o no debería estar expuesto.

---------------------------------------------
NODO 3 — audit-image
---------------------------------------------

Qué hace: audita las imágenes y contenedores Docker del equipo.

Herramientas:

  - Docker (requerido) → sin Docker este nodo no tiene sentido, por lo que
    bloquea si no está instalado.
  - Trivy (opcional) → escanea cada imagen Docker buscando CVEs en las
    dependencias que contiene.

Resultado: dashboard con la lista de imágenes y contenedores activos,
vulnerabilidades encontradas en cada imagen agrupadas por paquete afectado,
y avisos de configuración insegura (contenedor corriendo como root,
variables de entorno con contraseñas expuestas, puertos innecesarios).

---------------------------------------------
NODO 4 — audit-reporter (UI_TEMPLATES)
---------------------------------------------

Qué hace: recibe los hallazgos de los otros nodos y genera el informe final.

Resultado: dashboard HTML visual con todos los hallazgos agrupados por
severidad, con un botón "Copiar comando" en cada hallazgo para que el
usuario pueda aplicar la solución directamente desde el terminal.
